Privacy Policy

Last updated October 23, 2026

This policy covers the Old Road Tales website (oldroadtales.github.io) and Old Road Tales Drafts, the channel's own desktop tool for sending its finished videos to its TikTok and YouTube accounts as drafts.

Old Road Tales Drafts is used only by the owner of the Old Road Tales channel, on the owner's own computer, with the channel's own accounts. It isn't offered to anyone else, so the only account information it ever handles is the channel's own.

The website

The website is a few static pages. It has no cookies, analytics, ads, sign-in or forms, and it loads no scripts or fonts from anyone else. It is hosted on GitHub Pages. GitHub may record visitors' IP addresses in its server logs to keep the service secure; see the GitHub General Privacy Statement.

Old Road Tales Drafts and YouTube

Old Road Tales Drafts uses YouTube API Services. When the channel signs in with its Google account, the tool asks for one permission: to upload videos to the channel (youtube.upload).

  • It uses that permission only to upload the channel's own finished videos, with their title, description and tags. Each upload is set to private and marked as altered or synthetic content.
  • It does not read the channel's videos, comments, subscribers, analytics or any other account data.

Google's use of information is covered by the Google Privacy Policy.

Old Road Tales Drafts and TikTok

When the channel signs in with its TikTok account, the tool asks for two permissions: basic account information (user.info.basic) and uploading videos as drafts (video.upload).

  • It keeps only the account ID that TikTok returns at sign-in. It does not fetch the profile, followers, messages or anything else.
  • It uses the upload permission only to send the channel's own finished videos to the channel's TikTok inbox as drafts. The channel then checks each draft and posts it in the TikTok app. The tool never posts publicly.

TikTok's use of information is covered by the TikTok Privacy Policy.

What is stored, and where

  • The sign-in tokens from Google and TikTok, and the TikTok account ID, are stored in files on the owner's computer so the tool can stay signed in. Nothing else about the accounts is stored.
  • That information is sent only back to Google and TikTok, when the tool uploads a video. The tool has no server of its own.
  • Nothing is sold, shared with anyone else or used for advertising, and no third party serves content or ads through the tool or the website.
  • The tool keeps the tokens until they are signed out or access is revoked. Deleting the token files signs the tool out and removes them.

Revoking access

  • Google and YouTube: remove Old Road Tales at any time on Google's security settings page, security.google.com/settings/security/permissions. This works in addition to deleting the tool's token files.
  • TikTok: remove Old Road Tales Drafts from the apps connected to the account in the TikTok app's settings.

Children

The website and the tool are not directed at children under 13, and the tool collects no information from anyone other than the channel itself.
